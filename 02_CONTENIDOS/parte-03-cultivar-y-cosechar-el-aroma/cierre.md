# Cierre de la Parte 3 · El calendario de una parcela aromática

Diseñá el calendario de una parcela pequeña con cuatro especies. Para cada una registrá necesidades de agua, abonado, poda y momento de cosecha. Después completá un registro de secado con método, temperatura y humedad objetivo.
