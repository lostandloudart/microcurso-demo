# Construí una mezcla defendible

Diseñá una mezcla completa: tres aceites con sus notas, formato, vehículo, cantidad exacta, evolución aromática, modo de aplicación y lista de advertencias. La ficha final debe explicar tanto lo que la mezcla ofrece como aquello que no promete.
