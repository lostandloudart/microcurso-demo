# Control visual

Antes de publicar una imagen o una página, verificar:

- [ ] La imagen figura en el inventario.
- [ ] El recorte no contiene encabezados ni números de página.
- [ ] La información original no fue alterada.
- [ ] El texto y los rótulos son legibles.
- [ ] Hay texto alternativo, epígrafe y observación guiada.
- [ ] La imagen no domina la pantalla ni se deforma.
- [ ] No existe desplazamiento horizontal a 360 px.
- [ ] No hay superposiciones a 360, 768 o 1440 px.
- [ ] Los popups funcionan con teclado, ratón y tacto.
- [ ] El peso de los archivos publicados es razonable.
