# Control de seguridad

Antes de aprobar contenido sobre usos cosméticos o aromáticos, verificar:

- [ ] No se recomienda ingestión.
- [ ] No se indica aplicación directa sin un marco seguro.
- [ ] No se diagnostican ni tratan enfermedades.
- [ ] No se prometen curas ni resultados terapéuticos.
- [ ] Se explican límites, dilución, conservación y precauciones cuando corresponde.
- [ ] Se diferencia aprendizaje de elaboración o comercialización habilitada.
- [ ] Toda información regulatoria está respaldada por MSP, IMPO o MERCOSUR.
